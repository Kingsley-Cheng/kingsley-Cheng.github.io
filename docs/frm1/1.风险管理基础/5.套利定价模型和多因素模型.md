## 套利定价理论与风险因素
### 套利定价理论和CAPM
**套利定价理论**

==套利定价理论(arbitrage pricing theory，APT)==：当市场上无套利机会时，投资组合的期望收益率可以表达为多个因子(several factors)的线性函数
- 提出者：1976年，斯蒂芬·罗斯《资本资产定价的套利理论》
- 以多因素模型为基础，描述收益率和风险间的关系
$$
E(R_p) = R_f+\beta_{p,1}\lambda_1+\beta_{p,2}\lambda_2+\cdots+\beta_{p,K}\lambda_K
$$
- $E(R_p)$：投资组合 $P$ 的期望收益率
- $R_f$：无风险收益率
- $\beta_{p,k}$：因子 $k$ 的载荷(factor loading)，代表投资组合 $P$ 的收益率对风险因子 $k$ 的敏感程度
- $\lambda_k$：因子 $k$ 的风险溢价(factor risk premium)

**APT的基本假设**
- 资产的收益率能被影响所有证券的系统性因素(systematic factors)解释
- 通过分散化，投资者可以完全消除投资组合的特有风险/特异性风险(specific risk/idiosyneratic risk)
- 充分分散化的投资组合之间不存在套利机会。当出现套利机会时，投资者会实施套利，从而使套利机会消除。

**比较APT和CAPM**
- 相同点
  - 均是市场均衡前提下的资产定价
  - 都假设资产的特有风险能够通过分散化投资完全消除，只有影响所有资产的系统性因素才能够产生回报
- 不同点
  - APT模型是多因素模型，允许使用多个风险因素解释风险资产的收益率，适用范围更加广泛；CAPM模型是单因素模型，仅使用市场风险溢价解释收益率，可视为APT模型的特例
  - APT模型关于市场的假设仅为不存在任何套利机会，对投资者行为没有任何假设；CAPM模型包含一系列假设条件

**一价定律**

==一价定律==：如果两种资产所有的经济特性均相同，那么这两种金融工具的价格就应当相同
### 因素模型的种类
==宏观经济因素模型==：以宏观经济相关的变量作为多因素模型的因子，如利率、通货膨胀率、工业生产值等

==基本面因素模型==：以公司或行业层面的财务和经营特征作为多因素模型的因子，如公司规模、市盈率、账面/市值比率、收人增长率等

==统计因素模型==：基于历史数据，采用主成分分析等统计方法提取最能解释资产收益率的因子
### 法玛-弗伦奇三因素模型
$$
E(R_p) = R_f+\beta_{P,M}[E(R_M)-R_f]+\beta_{P,\text{SMB}}E(\text{SMB})+\beta_{p,\text{HML}}E(\text{HML})
$$
- $E(R_p)$：投资组合 $P$ 的期望收益率
- $R_f$：无风险收益率
- $\beta$：风险因子的 $\beta$ 系数，代表投资组合 $P$ 的收益率对各风险因素的敏感程度
- $E(R_M)-R_f$：CAPM 模型中的市场风险溢价
- SMB：小减大(small minus big)，规模因子，代表小市值股票收益率与大市值股票收益率的差，反映规模较小的公司相对于规模较大的公司的风险溢价
- HML：高减低(high minus low)，价值因子，代表高账面/市值比率的股票与低账面/市值比
率的股票收益率的差，反映价值型股票(高账面/市值比率)相对于成长型股票低账面/市值比率)的风险溢价

通常采用回归方法估计 $\beta$ 系数，回归方程为
$$
R_{pt}-R_{ft} = \alpha_P+\beta_{P,M}[R_{Mt}-R_{ft}]+\beta_{P,\text{SMB}}\text{SMB}_t+\beta_{p,\text{HML}}\text{HML}_t+\varepsilon_{Pt}
$$
- $alpha_P$：截矩项，表示投资组合收益率相对于补偿系统性风险要求的收益率的超额收益
  - 如果模型中的三个因素能覆盖所有系统性风险，在市场处于均衡状态时，$\alpha_P$应等于0。
## 其他有关问题
### 利用套利定价理论解释资产实际收益率
根据APT理论，多因素模型可以解释资产实际平均收益率与期望收益率的差异
$$
R_i = E(R_i)+\beta_{i,1}[I_1-E(I_1)]+\beta_{i,2}[I_2-E(I_2)]+\cdots+\beta_{i,K}[I_K-E(I_K)]+e_i
$$
- $R_i$：资产 $i$ 的实际收益率
- $E(R_i)$：资产 $i$ 的期望收益率
- $\beta$：回归系数，代表资产 $i$ 的收益率对因素 $k$ 变动的敏感程度
- $I_K-E(I_K)$：意外因素(suprise factor)，因素 $k$ 观察值和期望值的差异
- $e_i$：噪声因素(noise factor) / 特异性因素(idiosyncratic factor)，实际收益率中无法被解释的部分
### 基于因子的风险对冲
基于多因素模型中风险因子的 $\beta$ 系数，可以构建风险对冲组合来消除系统性风险
- 将每个风险因子看作一种基础证券，针对每个风险因子建立 $\beta$ 值相反的头寸

**存在的挑战**
- 合理确定对冲调整的频率：如果对冲长期不调整，净风险敞口将扩大。但如果对冲调整过于频繁，将造成交易成本上升，拖累整体投资业绩。
- 模型风险，包括模型本身的错误和模型使用中的错误。
  - 模型本身的错误：模型构建时可能有数学错误或不恰当的假设
## Exercise
::: note 例题 1
已知无风险收益率为 5%，根据下表中的信息，使用APT模型计算投资组合的期望收益率。

:::table
||风险因素1|风险因素2|
|:---:|:---:|:---:|
|贝塔系数|1.8|0.9|
|风险溢价/%|1.5|2|
:::

::: tip 答案
$E(R_p)=5\%+1.8*1.5\%+0.9*2\%=9.5\%$
:::

::: note 例题 2
分析师用法玛-弗伦奇三因素模型计算某公司的预期收益率，已知条件如下表所示

:::table
|项目|$\beta$ 值|
|:---:|:---:|
|$E(R_M)-R_f$|0.25|
|SMB|1.25|
|HML|-0.75|

分析师预期无风险收益率为 3%，市场组合收益率为 12.5%，SMB为 3.5%，HML为 0.02%。根据法玛-弗伦奇三因素模型，公司的预期收益率是多少?
:::

::: tip 答案
$E(R_p)=3\%+9.5\%*0.25+3.5\%*1.25-0.02\%*0.75=9.735\%$
:::

::: note 例题 3
分析师用法玛-弗伦奇三因素模型计算某公司的期望收益率，已知条件如下表所示。

:::table
||$\beta$ 值|风险溢价/%|
|:---:|:---:|:---:|
|市场|0.25|11|
|SMB|1.25|3.5|
|HML|-0.75|0|

分析师认为，该公司的收益率不能完全用法玛-弗伦奇三因素模型解释，这部分不能解释的收益率为每年3%。假设无风险利率为1.5%，市场指数收益率为12.5%。请计算该公司的预期收益率
:::

::: tip 答案
$E(R_p)=4.5\%+11\%*0.25+3.5\%*1.25=11.625\%$
:::

::: note 例题 4
假设某公司股票去年的收益率为 5%。该股票收益率无法被两因素模型解释的部分为 3%。使用下表给定的信息，计算该公司股票的期望收益率是多少。

:::table
|因素|实际水平/%|预期水平/%|$\beta$ 因子|
|:---:|:---:|:---:|:---:|
|利率的变动|2.0|0.0|-1.5|
|GDP的增长率|1.0|4.0|2|
:::

::: tip 答案
由于 $5\%=E(R_i)+2*(-3\%)-1.5*(2\%)+3\%$，因此 $E(R_i)=11\%$
:::

::: note 例题 5
分析师正在预测股票 A 对各宏观因素的敏感性。以下是已知的预测信息：$\beta_{\text{GDP growth}}=1.3,\beta_{\text{interest rate}}=-0.75$。GDP 增长率为 3%，利率为 1.5%，股票 A 的期望收益率为 5%。经济研究院预测下一年的经济活动会有所加速，预计 GDP 增长率会达到 4.2%，利率增长 25 个基点到 1.75%。根据新的预测，股票 A 下一年的收益率会是多少?
- A. 4.8%
- B. 6.4%
- C. 6.8%
- D. 7.8%
:::

::: tip 答案
$R_i=5\%+1.3*(4.2\%-3\%)-0.75*0.25\%=6.3725\%$，因此选 B
:::

::: note 例题 6
下表列出了三种风险资产及其 $\beta$ 系数。假设投资者拥有价值 USD 1000000 的资产A。该投资者如何对冲所有的风险因子?

::: table
|风险因子的系数|资产 A|资产 B|资产 C|
|:--:|:--:|:--:|:--:|
|$\beta_1$|1.5|0.8|-1.2|
|$\beta_2$|1.4|-0.6|0.2|
:::

::: tip 答案
设 1 份资产 A 需要 $x$ 份资产 B 和 $y$ 份资产 C 进行对冲，则满足
$$
\left\{
    \begin{array}{l}
        0.8x-1.2y+1.5=0\\
        -0.6x+0.2y+1.4=0
    \end{array}
\right.
$$
求解得
$$
\left\{
    \begin{array}{l}
        x=3.53571429\\
        y=3.60714286
    \end{array}
\right.
$$
因此，买进 USD 3535714.29 的资产 B 和 USD 3607142.86 的资产 C
:::
