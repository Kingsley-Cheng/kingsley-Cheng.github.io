## 市场需求

### 需求的含义
==需求==：在一定时间内和一定价格条件下，消费者对某种商品或与服务**愿意而且能够购买**的数量
- ==市场需求==：在一定时间内、一定价格条件下和一定的市场上**所有的消费者**对某种商品或服务**愿意而且能够购买**的数量

### 影响需求的主要因素

::: table
|主要因素|内容|
| :---: | :---: |
| 消费者偏好 | - 消费者偏好支配着他在替代品之间的消费选择<br> - 消费者偏好增强，需求增加 |
| 消费者的个人收入 | 消费者收入增加，需求增加 |
| 预期 | 消费者预期产品价格要上涨，会刺激人们提前购买 |
| 产品价格 **（最关键的因素）** | 价格和需求的变动呈反方向变化 |
| 替代品的价格 | 商品的需求与替代品的价格呈同方向变化 |
| 互补品的价格 | 商品需求与互补品的价格呈反方向变化 |
| 其他因素 | 商品品种、质量、广告宣传、地理位置、季节、国家政策等 |
:::

## 需求函数、需求规律及需求曲线

==需求函数==：一种商品的需求量与影响该需求量的各种因素之间的相互关系。假定价格之外的其他各因素不变的情况下，需求函数为
  $$
  Q_d=Q_d(P)
  $$

==需求规律==：需求量与价格之间呈反方向变化的关系

==需求曲线==：向**右下方倾斜**的曲线，横轴表示需求量，纵轴表示价格
- 产品价格因素的影响：需求量的变化**沿着既定的需求曲线**进行
- 非价格因素的影响：需求曲线的位移
- 市场需求曲线是所有个别消费者需求曲线**水平加总**

## 市场供给

### 供给的含义及影响供给的因素

**供给及市场供给**

- ==供给==：某一时间内和一定价格水平下，**生产者愿意并可能**为市场提供某种商品或服务的数量
  - ==市场供给==：所有生产者供给的总和

**影响供给的因素**

::: table
|影响因素|内容|
| :---: | :---: |
| 产品价格 | 产品价格和供给变动呈正方向变化 |
| 生产成本 | 产品成本和供给变动呈反方向变化 |
| 预期 | 生产者预期价格下降，供给增加 |
| 生产技术 | 技术水平在一定程度上决定着生产成本并进而影响供给 |
| 相关产品的价格 | / |
| 其他因素 | 生产要素的价格以及国家政策等 |
:::

### 供给函数、供给规律和供给曲线
==供给函数==：表示某一种商品的供给量和影响该供给量的各种因素之间的相互关系，假定只考虑产品价格因素，则 
$$
Q_s=Q_s(P)
$$

==供给规律==：供给量与市场价格之间**呈同方向变化**的关系

==供给曲线==：**向右上方倾斜**的曲线
- 产品价格因素的影响：供给量的变化**沿着既定的供给曲线**进行
- 非价格因素的影响：**供给曲线的位移**

## 均衡价格

### 均衡价格和均衡数量的形成和变动
==均衡价格==：供给量和需求量相等时的价格

==均衡数量==：达到均衡价格时的供求数量

- 任何市场上的供求平衡都是偶然的、暂时的、相对的
- **商品价值是决定商品价格的基础**，商品的价格总是在市场供给和市场需求关系的影响下围绕价值上下波动

### 均衡价格模型的运用

==最高限价==:由政府为某种产品价格上涨幅度过大规定一个具体的价格，市场交易只能在这一价格之下进行
- 目的：保护消费者利益或降低某些生产者的生产成本
- 影响：最高限价低于均衡价格，会刺激消费、限制生产，使供给减少、需求增加，结果是市场短缺
- 后果
    - 当实施最高限价而出现短缺现象时，市场就会出现严重的**排队**现象
    - 黑市交易和黑市高价
    - “走后门”现象
    - 生产者变相涨价等现象
- 措施：配给制

==保护价格==：由政府为某种产品价格下降幅度过大规定一个具体的价格，市场交易只能在这一价格之上进行
- 目的：保护生产者的利益或支持某一产业的发展（支持农业生产和稳定农民收入水平）
- 后果
    - 出现过剩现象
    - 黑市交易和黑市低价
    - 生产者变相降价等现象
- 措施：建立政府的收购和储备系统

## 弹性

### 需求价格弹性

**需求价格弹性的定义** 

==需求价格弹性==：需求量对价格变动的反应程度，是需求量变动百分比与价格变动百分比的比率 

$$
E_d=\dfrac{\Delta Q/Q}{\Delta P/ P}
$$

**需求价格弹性系数的计算公式**

==点弹性==：需求曲线某一点上的弹性，适用于**价格和需求量变动较小的场合**
$$
E_d=\dfrac{\Delta Q/Q_0}{\Delta P/ P_0}
$$

==弧弹性==：需求曲线上两点之间弧的弹性，适用于**价格和需求量变动较大的场合**

$$
E_d=\dfrac{\Delta Q}{(Q_0+Q_1)/2} / \dfrac{\Delta P}{(P_0+P_1)/2}
$$

**需求价格弹性的基本类型** 
- ==需求富有弹性 / 高弹性==：$E_d>1$，需求量变动百分数**大于**价格变动百分数
- ==需求缺乏弹性 / 低弹性==：$E_d<1$，需求量变动百分数小于价格变动百分数
- ==需求单一弹性==：$E_d=1$，需求量变动百分数**等于**价格变动百分数

**影响需求价格弹性的因素** 

::: table
|影响因素|内容|
|:---:|:---:|
|替代品的数量和相近程度|相近的替代品越多，需求价格弹性大|
|商品的重要性|生活基本必需品，需求弹性小，非必需的高档商品，需求弹性大|
|商品用途|商品的用途越多，需求弹性越大|
|时间|时间越短，商品的需求弹性越缺乏，时间越长，商品的需求弹性就越大|
:::

**需求价格弹性和总销售收入的关系**

- $E_d>1$：销售收入与价格变动呈反方向变动趋势，适用实行**薄利多销**的方法
- $E_d<1$：销售收入与价格变动呈同方向变动趋势
- $E_d=1$：价格变动不会引起销售收入的变动

### 需求交叉弹性

**需求交叉价格弹性的定义和公式**

==需求交叉价格弹性==：需求交叉弹性是指一种商品价格的相对变化与由此引起的另一种商品需求量相对变动之间的比率
$$
E_{ij}=\dfrac{商品i需求量的相对变化}{商品j价格的相对变化}
$$

**需求交叉弹性的类型**

- $E_{ij}>0$：替代关系
- $E_{ij}<0$：互补关系
- $E_{ij}=0$：不存在相关关系

### 需求收入弹性

**需求收入弹性的含义和公式** 

==需求收入弹性==：需求量的变动和引起这一变动的消费者收入之比，用以衡量需求变动对消费者收入变动的反应程度 

$$
E_y=\dfrac{\Delta Q / Q}{\Delta y/y}
$$

**需求收入弹性的类型** 

- $E_y>1$：收入多买的更多，高档品
- $E_y=1$：收入多买的一样多
- $0<E_y<1$：收入多买的略多，必需品
- $E_y=0$：不管收入如何变动，需求数量不变
- $E_y<0$：收入多，买的少，低档品

==恩格尔定律==：对于一个家庭或一个经济体来说，富裕程度越高，则食物支出的需求收入弹性就越小；反之，则食物支出的需求收入弹性就越大

### 供给价格弹性

**供给价格弹性的定义和公式**

==供给价格弹性==：供给量对价格变动的反应程度，是供给量变动百分比与价格变动百分比的比率 

$$
供给价格弹性系数=\dfrac{供给量的相对变化}{价格的相对变化}
$$

**供给价格弹性的类型** 

- ==供给价格弹性充足==：供给价格弹性系数>1
- ==供给价格弹性不充足==：供给价格弹性系数<1
- ==供给单位弹性==：供给价格弹性系数=1
- ==供给完全无弹性==：供给价格弹性系数=0：
- ==供给完全有弹性==：供给价格弹性系数=$\infty$

**影响供给价格弹性的因素**

::: table
|影响因素|内容|
|:---:|:---:|
|时间（决定供给弹性的首要因素）|短期内，供给弹性一般较小；长期内，供给弹性一般比较大|
|生产周期和自然条件|生产周期越长，供给弹性越小<br>自然条件会导致供给的不确定性|
|投入品替代性大小和相似程度|投入品替代性大，相似程度高，则供给弹性大<br>投入品难以加入或脱离某种特定行业，则供给缺乏弹性|
:::
