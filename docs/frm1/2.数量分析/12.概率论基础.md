## 一、随机事件与概率

### 基本概念

==随机变量(random variable)==：随机现象可能产生的结果，一般用大写字母$X,Y,Z$表示

==结果(outcome)==：随机变量可能的取值，结果的具体取值一般用小写字母表示

==样本空间(sample space)==：随机变量的所有可能结果组成的集合，用$\Omega$表示

==事件(event)==：随机变量部分结果组成的集合，也称为随机事件，一般用大写字母$A,B,C$表示
- 本质是集合，可以是样本空间的任意子集，包括空集和全集
- 集合中任意一个结果发生，就称该事件发生

==事件空间(event space)==：所有事件的集合，一般用$F$表示

==概率==：某个事件发生的可能性，事件$E$发生的概率记为$P(E)$。概率满足
- $0\leq P(E)\leq1$
- 对于一组互斥且遍历事件$E_i$，$\sum_i P(E_i)=1$

### 事件的类型

==互斥事件(mutually exclusive events)==：一组不可能同时发生的事件，即$AB=\emptyset$

==遍历事件(exhaustive events)==：一组包含随机变量所有可能结果的事件，即$A\cup B=\Omega$

==独立事件(independent events)==：一个事件的发生不会影响到另一个事件发生，即$P(AB)=P(A)P(B)$
- 如果事件$A、B$发生的概率不为0，则独立事件一定不是互斥事件，互斥事件一定不是独立事件

==条件独立事件==：$P(AB|C)=P(A|C)P(B|C)$
- 条件独立是无条件独立的既非充分又非必要条件

### 乘法法则与加法法则

==条件概率(conditional probability)==：已知事件$B$发生的情况下，事件$A$发生的概率，记为$P(A|B)$

==联合概率(joint probability)==：事件$A$与事件$B$同时发生的概率，记为$P(AB)$

==乘法法则(multiplication rule)==
$$
P(AB)=P(A)P(B|A)=P(B)P(A|B)
$$

- 对于独立事件：$P(AB)=P(A)P(B)$

==加法法则(addition rule)==
$$
P(A+B)=P(A)+P(B)−P(AB)
$$

## 全概率公式与贝叶斯公式

### 全概率公式
==全概率公式(total probability theorem)==: 假设事件$A_1,A_2,\cdots,A_n$互斥且遍历，则
$$
P(B)=\sum_1^nP(B|A_i)P(A_i)
$$

### 贝叶斯公式
==贝叶斯公式(Bayes' rule)==
$$
P(A|B)=P(B|A)P(B)P(A)
$$
- ==先验概率(prior probability)==: $P(A)$
- ==后验概率(updated probability)==: $P(A|B)$

## Exercise
::: note 例题 1
Tom每天可以选择乘坐不同的交通工具上班。乘坐公交车时，他有20%的概率会迟到；乘坐地铁时，他有90%的概率能够准时；骑自行车时，他有80%的概率能够准时。假设Tom每天选择公交车、地铁或自行车的概率分别为35%、30%和35%。已知汤姆今天上班迟到了，那么他没有选择公交车也没有选择地铁的概率是多少?  
- A. 33.73%
- B. 58.82%
- C. 41.18%
- D. 66.27%
:::

::: tip 答案
C
:::

::: note 例题 2
根据事件的关系，事件可以分为不同的类型。有两种最常用的方法对事件进行分类。一方面，事件可以是独立的(independent)，也可以是非独立的(dependent)；另一方面，事件可以分为互斥事件(mutually exclusive events)和遍历事件(exhaustive events)。以下关于事件之间关系的陈述中哪一项最准确?  
- A. 独立事件必须是互斥的
- B. 互斥的两个事件必须是独立的
- C. 事件的独立性与事件的互斥性无关
- D. 互斥事件意味着其中一个事件的发生意味着另一个事件不发生
:::

::: tip 答案
D
:::

::: note 例题 3
如果经济不陷入衰退，某公司有80%的概率保持增长。明年经济有40%的概率衰退，40%的概率正常，20%的概率繁荣。那么明年经济不陷入衰退且该公司同时保持增长的概率是:  
- A. 45%
- B. 48%
- C. 50%
- D. 55%
:::

::: tip 答案
B
:::

::: note 例题 4
掷骰子中，若事件 $A$ 为“掷出偶数点”，事件 $B=\{1,2,3,5\}$。事件 $A$ 与事件 $B$ 是否为互斥事件，是否为遍历事件?
:::

::: tip 答案
事件 $A$ 与事件 $B$ 不是互斥事件，是遍历事件
:::

::: note 例题 5
互斥事件是否为独立事件? 独立事件是否为互斥事件?
:::

::: tip 答案
互斥事件一定不是独立事件、独立事件一定不是互斥事件
:::

::: note 例题 6
假设美联储降息的概率为30%。如果美联储降息，则经济进入繁荣期的概率为80%。求经济进入繁荣期且美联储降息的概率。
:::

::: tip 答案
由于 $P(经济进入繁荣期|美联储降)=\dfrac{P(经济进入繁荣期\land美联储降)}{P(美联储降息)}=80\%$，$P(美联储降息)=30\%$

因此 $P(经济进入繁荣期\land美联储降)=0.24$
:::

::: note 例题 7
假设下一季度美联储加息概率 $P(I)$ 为 0.3。如果美联储加息，经济陷入衰退的概率为 $0.8$；反之，如果不加息，经济陷入衰退的概率为 $0.1$。求经济陷入衰退的无条件概率。
:::

::: tip 答案
由于 $P(下一季度美联储加息)=0.3$，$P(经济陷入衰退|美联储加息)=0.8$，$P(经济陷入衰退|美联储不加息)=0.1$

因此 $P(经济陷入衰退)=P(经济陷入衰退|加息)P(加息)+P(经济陷入衰退|不加息)P(不加息)=0.31$
:::

::: note 例题 8
测谎仪可以用于检测嫌犯是否撒谎。已知嫌犯撒谎的概率是 0.8。如果嫌犯撒谎，测谎仪测出其撒谎的概率为 0.9；如果嫌犯没有撒谎，测谎仪测出嫌犯撒谎的概率为 0.3。问测谎仪测出嫌犯撒谎的情况下，嫌犯真的撒谎的概率是多少?
:::

::: tip 答案
已知

::: table
||嫌犯撒谎|嫌犯不撒谎|合计|
|:---:|:---:|:---:|:---:|
|测出撒谎|0.8*0.9=0.72|0.2*0.3=0.06|0.78|
|没有测出撒谎|0.8-0.72=0.08|0.22-0.08=0.14|1-0.78=0.22|
|合计|0.8|1-0.8=0.21|

因此，$P(嫌犯撒谎|测出撒谎)=\dfrac{P(嫌犯撒谎\land测出撒谎)}{P(测出撒谎)}=92.308\%$
:::

::: note 例题 9
市场上的所有基金经理可归为三类：表现不佳的、表现中等的以及表现优异的。表现不佳的基金经理业绩超过市场的概率为 25%；表现中游的基金经理业绩超过市场的概率为 50%；表现优异的基金经理业绩超过市场的概率为 75%。根据经验数据，市场上有 60% 的基金经理属于中等的，20% 的基金经理属于表现不佳的，20% 的基金经理属于表现优异的。假设已知某基金经理连续两年业绩超过了市场，这个基金经理属于表现不佳的概率是多少?
:::

::: tip 答案
已知 
- $P(连续两年业绩超过了市场|表现不佳)=0.25\times0.25=\dfrac{1}{16}$
- $P(连续两年业绩超过了市场|表现中等)=0.5\times0.5=\dfrac{1}{4}$
- $P(连续两年业绩超过了市场|表现优异)=0.75\times0.75=\dfrac{9}{16}$

得 
- $P(连续两年业绩超过了市场)=\dfrac{1}{16}\cdot0.2+\dfrac{1}{4}\cdot0.6+\dfrac{9}{16}\cdot0.2=\dfrac{11}{40}$

因此
- $P(表现不佳|连续两年业绩超过了市场)=\dfrac{P(连续两年业绩超过了市场\land表现不佳)}{P(连续两年业绩超过了市场)}=4.55\%$
:::
