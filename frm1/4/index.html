投资组合理论与资产定价基础

现代投资组合理论(MPT)

现代投资组合理论(modern portfolio theory，MPT)

  • 提出者：1952年，哈里·马科维茨(Harry Markowitz)，《投资组合选择》(Portfolio Selection)
  • 均值-方差(mean-variance)分析框架：以算术均值衡量期望收益率、以方差或标准差衡量风险，用量化方式阐述了投资组合选择问题
  • 风险分散化：应将资金按比例分散投资于价值变动不完全相关的多种资产中

收益和风险的度量

资产的期望收益率

R=R1+R2+⋯+RnnR=\dfrac{R_1+R_2+\cdots+R_n}{n} R=nR1​+R2​+⋯+Rn​​

  • RRR：资产单期期望收益率
  • RiR_iRi​：资产在过去第 iii 期的收益率
  • nnn：数据期数

资产的风险

σ2=∑i=1N(Xi−μ)2N\sigma^2=\dfrac{\sum_{i=1}^N(X_i-\mu)^2}{N} σ2=N∑i=1N​(Xi​−μ)2​

  • σ2\sigma^2σ2：方差
  • XiX_iXi​：资产在过去第 iii 期的收益率
  • μ\muμ：均值
  • NNN：数据集中的个数

波动率(volatility)：使用标准差(standard deviation)度量风险，记为 σ\sigmaσ

MPT理论的假设

  • “理性投资者”(rational investor)：投资者厌恶风险、追求效用(utility)最大化
  • 资本市场是完美的
    • 不存在税收和交易成本
    • 所有交易者都可以零成本地获得所有可用信息
    • 所有市场参与者之间是完全竞争的
  • 资产收益率服从正态分布

效用理论

根据投资者面对不确定性的态度，可以划分为

  • 风险厌恶(risk averse)：在收益一定时，投资者希望最小化风险；在风险一定时，投资者希望最大化收益
    • 理性投资者追求效用最大化，倾向于投资期望收益率(以均值衡量)更高、风险(以方差衡量)更低的资产
  • 风险中性(risk neutral)：投资者追求收益最大化，不关注风险
  • 风险偏好(risk seeking)：投资者同时追求高收益和高风险

效用函数(utility function)：基于风险和收益构建的，用于计算投资组合效用的函数。常见效用函数

U=E(R)−12Aσ2U=E(R)-\dfrac{1}{2}A\sigma^2 U=E(R)−21​Aσ2

  • UUU：效用，E(R)E(R)E(R)：投资组合的期望收益率，σ2\sigma^2σ2：投资组合的方差，AAA：风险厌恶系数
  • AAA 越大表示风险厌恶程度越高，A>0A>0A>0 表示风险厌恶，A=0A=0A=0 表示风险中性，A<0A<0A<0 表示风险偏好

无差异曲线(indifference curve)：以收益率的标准差为横坐标、以期望收益率为纵坐标，在给定的效用水平上，无数种风险---收益组合组成的曲线

  • 对风险厌恶型投资者，每条无差异曲线都向上倾斜，而且随着标准差增加，无差异曲线斜率越来越大
  • 风险厌恶程度越高的投资者，无差异曲线的斜率越大
  • 风险中性型投资者的效用等于期望收益率
  • 风险偏好型投资者在风险越大时，要求的收益越小，无差异曲线向下倾斜

有效前沿

投资组合(portfolio)：两种或两种以上资产组成的投资集合

假设风险资产 AAA 收益率为 RAR_{A}RA​、风险资产 BBB 收益率为 RBR_BRB​，A, BA,\ BA, B两种资产构成一个投资组合，在组合中的权重分别为 wAw_AwA​ 和 wBw_BwB​，且wA+wB=1w_A+w_B=1wA​+wB​=1

  • 投资组合的收益率 RpR_pRp​：Rp=wARA+wBRBR_p=w_AR_A+w_BR_BRp​=wA​RA​+wB​RB​

    • 投资资产 AAA 的同时，投资任何收益率与不完全正相关的资产 BBB(即 ρAB<1\rho_{AB}<1ρAB​<1)，都可以降低投资组合的标准差，并且 ρAB\rho_{AB}ρAB​ 越小，组合整体标准差降低的程度越大

最小方差前沿(minimum-variance frontier)：在相同收益率水平下，风险最小(方差最小)的投资组合构成的曲线

全球最小方差组合(global minimum variance portfolio)：最小方差前沿最左侧的点，即可行集内方差最小的投资组合

有效前沿(efficient frontier)：全球最小方差组合及其上方的最小方差前沿

  • 有效前沿上的组合既在一定收益水平下风险最小，又在一定风险水平下收益最大

最优投资组合选择

最优投资组合：有效前沿与无差异曲线的切点

资本市场理论

下面讨论当市场提供无风险资产时投资收益与风险之间的关系

资本配置线

无风险资产：提供确定的收益率、没有任何风险的资产，通常将美国三个月期国库券利率视为无风险收益率

假设投资组合仅包含无风险资产和一种风险资产

  • 投资组合的期望收益率：E(Rp)=wiE(Ri)+wfRfE(R_p)=w_iE(R_i)+w_fR_fE(Rp​)=wi​E(Ri​)+wf​Rf​
  • 投资组合的标准差：σp=wiσi\sigma_p=w_i\sigma_iσp​=wi​σi​
  • 资本配置线(CAL)：由于wi+wf=1w_i+w_f=1wi​+wf​=1，则E(Rp)=Rf+E(Ri)−RfσiσpE(R_p)=R_f+\dfrac{E(R_i)-R_f}{\sigma_i}\sigma_pE(Rp​)=Rf​+σi​E(Ri​)−Rf​​σp​
  • 夏普比率：E(Ri)−Rfσi\dfrac{E(R_i)-R_f}{\sigma_i}σi​E(Ri​)−Rf​​，表示平均风险溢价(收益率超过无风险收益率的部分)与风险的比值

最优CAL(optimal CAL)：与有效前沿相切的CAL，此时提供的效用最大

最优风险组合(optimal risky portfolio)：最优CAL与有效前沿的切点所代表的投资组合

  • 是所有CAL中斜率最大的，即夏普比率最大的投资组合

最优投资者组合(optimal investor portfolio)：存在无风险资产时，无差异曲线与最优CAL切点的组合

资本市场线

市场组合(market porfolio)：假设市场上所有投资者对所有风险资产都具有同质预期(homogeneous expectation)，那么所有投资者都有相同的风险资产有效前沿、最优风险组合和最优CAL。此时的的最优风险组合为市场组合

  • 市场组合存在的前提是市场均衡
  • 理论上，市场组合应包含市场上存在的所有风险资产，各资产的权重等于其市值的相对比重。

资本市场线(capital market line，CML)：市场组合和无风险资产构成的所有可能组合

E(Rp)=E(RM)−RfσMσp+RfE(R_p)=\dfrac{E(R_M)-R_f}{\sigma_M}\sigma_p+R_f E(Rp​)=σM​E(RM​)−Rf​​σp​+Rf​

“两基金分离定理”(two-fund separaion theorem)：理性投资者都应该在CML上配置资产，将资金在市场组合 MMM 和无风险资产之间分配，权重取决于投资者自身的风险容忍度

资本资产定价模型(CAPM)

资本资产定价模型是市场均衡条件下风险资产预期收益率的预测模型

CAPM模型的假设

  • 投资者都是厌恶风险、追求效用最大化的理性投资者
  • 投资者都计划相同时长的单期投资
  • 投资者都有相同的预期
  • 投资者都能按照相同的无风险利率借贷
  • 投资者都是价格接受者，单个投资决策不会影响市场价格
  • 市场上所有信息都是免费可用的，并且会即刻反映在资产价格中
  • 不存在交易成本、税收或其他市场摩擦
  • 投资可以无限分割，允许在每种资产中分配任何比例的资金
  • 所有的资产，包括人力资本，都是可交易的
  • 投资者都根据收益率均值和方差做出投资决策

系统性风险与非系统性风脸

系统性风险(systematic risk) / 不可分散风险(non-diversifiable risk) / 市场风险(market risk)：能影响整个市场或经济体的不可避免的风险，通常与宏观因素有关

  • 投资者仅能通过承担系统性风险获得回报，即收益仅来源于只有系统性风险

非系统性风险(unsystematic risk)/ 可分散风险(diversifable risk) / 公司特有风险(firm-specific risk) / 特异性风险(idiosyncratic risk)：仅影响特定资产、行业或地区的风险，可以通过持有充分分散化的(well-diversified)投资组合降低或消除

  • 投资组合中资产数量越多，非系统性风险越小，在资产数量足够大时，非系统性风险将趋近于0
  • 承担非系统性风险不会为投资者带来回报

β\betaβ 值：衡量资产的系统性风险，反映某种风险资产的收益率对市场整体收益率变动的敏感程度

βi=Cov(Ri,RM)σM2\beta_i=\dfrac{\text{Cov}(R_i,R_M)}{\sigma_M^2} βi​=σM2​Cov(Ri​,RM​)​

  • β>0\beta>0β>0：资产收益率倾向于与市场收益率同向变动
  • β<0\beta<0β<0：资产收益率倾向于与市场收益率反向变动
  • 市场组合收益率的方差(总风险)等于各风险资产的收益率与市场组合收益率之间协方差的加权平均，即

    ∑i=1NWiCov(Ri,RM)=σM2\sum_{i=1}^NW_i\text{Cov}(R_i,R_M)=\sigma_M^2 i=1∑N​Wi​Cov(Ri​,RM​)=σM2​

  • 市场上所有风险资产 β\betaβ 值的加权平均值等于1，即 ∑i=1NWiβi=1\sum_{i=1}^NW_i\beta_i=1∑i=1N​Wi​βi​=1
  • β\betaβ 值越大，说明证券的系统性风险越大、期望收益率也越大
  • β>1\beta>1β>1：激进型(aggressive)，β<1\beta<1β<1：防御型(defensive)

CAPM模型

E(Ri)=Rf+βi[E(RM)−Rf]E(R_i)=R_f+\beta_i[E(R_M)-R_f] E(Ri​)=Rf​+βi​[E(RM​)−Rf​]

  • E(Ri)E(R_i)E(Ri​)：资产 iii 的期望收益率，RfR_fRf​：无风险收益率，βi\beta_iβi​：资产 iii 的系统性风险，E(RM)E(R_M)E(RM​)：市场组合 MMM 的期望收益率
  • 市场风险溢价(market risk premium)：E(RM)−RfE(R_M)-R_fE(RM​)−Rf​，表示市场对投资者承担的每一单位系统性风险可以提供的补偿

证券市场线

证券市场线(security market line，SML)：以 βiβ_iβi​ 为横坐标、E(Ri)E(R_i)E(Ri​) 为纵坐标的直角坐标系中绘制的直线，反映了期望收益率和系统性风险的线性关系

  • 如资产或投资组合在SML下方，说明预测收益率低于理论均衡收益率，价格被高估(高于理论均衡价格)，应该卖出资产
  • 如资产或投资组合在SML上方，说明预测收益率高于理论均衡收益率，价格被低估(低于理论均衡价格)，应该买入资产
  • 如资产或投资组合位于SML上，说明预测收益率等于理论均衡收益率，定价合理。

业绩衡量指标

夏普比率(SPI)

夏普比率(Sharpe performance index/Sharpe ratio，SPI)：资产或投资组合的平均风险溢价与收益率标准差的比值

SPI=E(Ri)−Rfσi\text{SPI}=\dfrac{E(R_i)-R_f}{\sigma_i} SPI=σi​E(Ri​)−Rf​​

  • 衡量了每单位风险(总风险)产生的超额收益，SPI 指标越高，意味着风险调整收益率越高，投资业绩越好
  • 市场组合的SPI：E(RM)−RfσM\dfrac{E(R_M)-R_f}{\sigma_M}σM​E(RM​)−Rf​​，可作为业绩评价的基准

特雷诺比率(TPI)

特雷诺比率(Treynor performance index，TPI)：资产或投资组合的平均风险溢价与 β\betaβ 值的比值

TPI=E(Ri)−Rfβi\text{TPI}=\dfrac{E(R_i)-R_f}{\beta_i} TPI=βi​E(Ri​)−Rf​​

  • 衡量了每单位系统性风险产生的超额收益，TPI 指标越高，意味着风险调整收益率越高，投资业绩越好
  • 市场均衡时风险资产的TPI：E(RM)−RfE(R_M)-R_fE(RM​)−Rf​，可作为TPI的评价基准
  • 未考虑非系统性风险，假设投资者已经拥有充分分散化的投资组合

詹森阿尔法(JPI)

詹森阿尔法(Jensen's Alpha/Jensen's performance index,α\alphaα 值/JPI)：投资组合实际收益率与补偿系统性风险要求的收益率(由CAPM确定)的差

αi=Ri−(Rf+βi[E(RM)−Rf])\alpha_i=R_i-(R_f+\beta_i[E(R_M)-R_f]) αi​=Ri​−(Rf​+βi​[E(RM​)−Rf​])

  • 衡量了投资组合实际收益率相对于CAPM理论收益率的超额收益，JPI越高说明投资业绩越好
  • 未考虑非系统性风险，假设投资者已经拥有充分分散化的投资组合
  • 在市场均衡时，JPI等于0，如果投资组合的JPI大于0，说明其收益率超过了理论均衡收益率，业绩表现较好
  • 通常使用一元线性回归的方法估计投资组合的 α\alphaα 值和 β\betaβ 值
  • TPI=αiβi+[E(RM)−Rf]\text{TPI} = \dfrac{\alpha_i}{\beta_i}+[E(R_M)-R_f]TPI=βi​αi​​+[E(RM​)−Rf​]
  • 当评价某个投资组合业绩优劣时，只要 β\betaβ 值大于0，使用TPI或JPI指标将得到一致的结论，但排序的结果可能有差异。

索提诺比率(SR)

索提诺比率(Sortino ratio，SR)：超额收益与风险的比值

SR=E(Rp)−T1N∑i=1Nmin⁡(0,RPt−T)2\text{SR}=\dfrac{E(R_p)-T}{\sqrt{\dfrac{1}{N}\sum_{i=1}^N}\min(0,R_{Pt}-T)^2} SR=N1​∑i=1N​​min(0,RPt​−T)2E(Rp​)−T​

  • E(Rp)E(R_p)E(Rp​)：投资组合 PPP 的期望收益率，TTT：目标收益率或必要收益率，RPtR_{Pt}RPt​：投资组合 PPP 在 ttt 时刻的收益率，NNN：收益率数据量

SR与SPI的差异

  • SR 的分母是下行偏差(down side deviation)：下行偏差仅考虑收益率低于T的差异、忽略收益率高于T的差异
  • SR 的分子是期望收益率与T的差。

主动管理的业绩衡量指标

主动收益

主动收益(active return)：投资组合收益率相对于基准收益率的超额收益，反映由于投资组合管理者的资产配置与基准组合资产配置不同产生的回报

Active Return=Rp−RB\text{Active Return} = R_p-R_B Active Return=Rp​−RB​

  • RpR_pRp​：投资组合 PPP 的收益率，RBR_BRB​：指定的基准组合 BBB 的收益率

追踪误差

追踪误差(tracking error，TE)：主动收益的标准差，衡量组合管理的主动风险

TE=σRp−RB\text{TE} = \sigma_{R_p-R_B} TE=σRp​−RB​​

  • 追踪误差越低，意味着投资组合的收益率变动与基准组合的收益率变动一致性越强

信息比率

信息比率(information ratio，IR)：投资组合主动收益与主动风险的比值

IR=Average Active ReturnTE=Rp−RB‾σRp−RBIR = \dfrac{\text{Average Active Return}}{\text{TE}}=\dfrac{\overline{R_p-R_B}}{\sigma_{R_p-R_B}} IR=TEAverage Active Return​=σRp​−RB​​Rp​−RB​​​

  • 考察主动投资的有效性，判断投资组合管理者偏离基准组合承担的额外风险是否获得了足够的额外收益补偿
