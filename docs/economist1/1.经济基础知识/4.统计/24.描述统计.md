对数据分布特征的测度：
- 分布的**集中趋势**：反映数据向其中心值靠拢或聚集的程度
- 分布的**离散程度**：反映各数据之间的差异程度，也能反映中心值对数据的代表程度
- 分布的**偏态**：反映数据分布的不对称性

## 集中趋势的测度

### 均值

==集中趋势==：一组数据向某一中心值靠拢的程度

**均值**

==均值 / 平均数==：数据组中所有数值的总和除以该组数值的个数。特征：
- 集中趋势最主要的测度值，是一组数据的重心所在，解释了一组数据的平均水平
- 主要适用于**数值型数据**，不适用于分类数据和顺序数据
- 易受极端值的影响

### 中位数和众数

**中位数**

==中位数==：把一组数据按从小到大或从大到小的顺序进行排列，位置居中的数值。
- 计算：若 $n$ 为数据个数
    - $n$ 为奇数：中位数位于 $(n+1)/2$
    - $n$ 为偶数：中位数是位于 $n/2$ 与 $n/2+1$ 的数据的平均值
- 适用范围
    - 位置代表值，主要适用于**顺序数据和数值型数据**，不适用于分类数据
    - 不受极端值的影响，抗干扰性强，尤其适用于收入这类偏斜分布的数值型数据

**众数**

==众数==：一组数据中出现次数（频数）最多的变量值

- 适于描述**分类数据和顺序数据**的集中趋势，数不适用于描述定量数据的集中位置

### 均值、中位数和众数的比较
:::table
| 指标   | 适用范围           | 是否受极端值影响 | 是否利用数据的全部信息 |
| :------: | :------------------: | :----------------: | :----------------------: |
| 众数   | 分类变量、顺序变量 | 否               | 否                     |
| 中位数 | 顺序变量、定量变量 | 否               | 否                     |
| 平均数 | 定量变量           | 是               | 是                     |
:::
## 离散程度的测度

### 方差和标准差

==离散程度==：数据之间的差异程度。数据的离散程度越大，集中趋势的测度值对该组数据的代表性就越差

**方差和标准差**
- 只适用于**数值型数据**，对极端值很敏感
- 不能直接用它们比较不同变量的离散程度

==方差==：数据组中各数值与其均值离差平方的平均数
- 方差越小，数据值与均值的平均距离越小，均值的代表性越好
- 方差的单位是原数据的平方,没有解释意义

==标准差==：方差的平方根
- 不仅能度量数值与均值的平均距离，还与原始数值具有相同的计量单位
- 标准差越小，说明数据值与均值的平均距离越小，均值的代表性越好

### 离散系数

==离散系数 / 变异系数 / 标准差系数==：标准差与均值的比值
- 消除了测度单位和观测值水平不同的影响，主要用于不同类别数据离散程度的比较
- 只适用于**数值型数据**

## 分布形态的测度

### 分布形态的测度指标

分布形态的测度指标包括**偏态系数和标准分数**

**偏态系数**

==偏度==：数据分布的偏斜方向和程度，描述的是数据分布的对称程度

==偏态系数==：测度数据分布偏度的统计量，是离差三次方的平均数与标准差三次方的比值
- 偏态系数的绝对值越大，数据分布的偏斜程度越大

:::table
|取值|分布|
|:--:|:--:|
|偏态系数=0|分布对称|
|偏态系数>0|分布右偏|
|偏态系数<0|分布左偏|
|偏态系数在0和0.5之间|轻度偏斜|
|偏态系数在0.5和1之间|中度偏斜|
|偏态系数>1|重度偏斜|
:::

**标准分数（“Z”分数）** 

==标准分数==： 
$$
\text{标准分数} = \dfrac{\text{原始分数}-\text{均值}}{\text{标准差}}
$$
- 适用范围：比较不同变量的取值
- 当数据服从对称的钟形分布时
    - 68%：标准分数在[-1，1]范围内
    - 95%：标准分数在[-2，2]范围内
    - 99%：标准分数在[-3，3]范围内

## 变量间的相关分析

### 变量间的相关关系

:::table
|标准|分类|内容|
|---|---|---|
|相关的程度{colspan=1 rowspan=3}|完全相关|一个变量的取值变化完全由另一个变量的取值变化所确定|
||不完全相关|介于完全相关和不相关之间|
||不相关|两个变量的取值变化彼此互不影响|
|相关的方向{colspan=1 rowspan=2}|正相关|两个变量同方向变化|
||负相关|两个变量反方向变化|
|相关的形式{colspan=1 rowspan=2}|线性相关|两个变量同方向变化|
||非线性相关|两个相关变量之间的关系近似于某种曲线方程的关系|
:::

### 相关关系的度量（散点图和相关系数）

==散点图==：每个点代表一个观测值，横纵坐标值分别代表两个变量相应的观测值

**相关系数** 

==相关系数==：度量两个变量之间相关关系的统计量。最常用的是 Pearson（皮尔逊）相关系数
- Pearson 相关系数的取值范围在[-1,1]之间

::: table
|取值|相关关系|
|:--:|:--:|
|$0<r<1$|不完全正线性相关|
|$-1<r<0$|不完全负线性相关|
|$r=1$|完全正线性相关|
|$r=-1$|完全负线性相关|
|$r=0$|不存在线性相关关系|
|$\vert r\vert\geq0.8$|高度相关|
|$0.5\leq\vert r\vert<0.8$|中度相关|
|$0.3\leq\vert r\vert<0.5$|低度相关|
:::
