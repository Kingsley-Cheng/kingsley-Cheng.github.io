27. 时间序列分析

约 1798 字大约 6 分钟

2026-09-29

时间序列及其分类

时间序列：将某一统计指标在各个不同时间上的数值按时间先后顺序编制形成的序列

时间序列构成要素

  • 被研究现象所属时间
  • 反映该现象一定时间条件下数量特征的指标值

时间序列的分类

时间序列主要内容
绝对数时间序列时期序列：反映现象在一定时期内发展的结果，是过程总量（国内生产总值时间序列）
时点序列：反映现象在一定时点上的瞬间水平（年末总人口时间序列）
相对数时间序列统计指标值是相对数（城镇人口比重时间序列）
平均数时间序列统计指标值是平均数（人均国内生产总值时间序列）

时间序列的水平分析

平均发展水平的计算

发展水平的有关概念

概念含义
发展水平时间序列中对应于具体时间的指标数值
最初水平时间序列中第一项的指标值
最末水平时间序列中最末项的指标值
中间水平时间序列中处于最初水平和最末水平之间的各期指标值
基期水平作为对比的基础时期的水平
报告期水平所要反映与研究的那一时期的水平
平均发展水平 / 序时平均数 / 动态平均数对时间序列中各时期发展水平计算的平均数

平均发展水平的计算

绝对数时间序列序时平均数的计算

时间序列计算方式
时期序列简单算术平均数
时点序列由连续时点（逐日登记）计算
- 资料逐日排列且每天登记：简单算术平均数
- 资料登记的时间单位仍然是天，但实际上只在指标值发生变动时才记录一次：加权算术平均数
由间断时点（不逐日登记）计算
- 每隔相等时间登记：先求各时间间隔内的平均数，再对平均数简单算术平均
- 每隔不等时间登记：第一次计算各时间间隔内的平均数；第二次平均用间隔长度作为权数，计算加权

相对数或平均数时间序列序时平均数的计算

  • 分别求出分子指标和分母指标时间序列的序时平均数，然后再进行对比

增长量与平均增长量

增长量：反映报告期比基期增加（或减少）的绝对数量

增长量=报告期水平−基期水平\text{增长量} = \text{报告期水平}-\text{基期水平} 增长量=报告期水平−基期水平

  • 逐期增长量=报告期水平−报告期前一期水平\text{逐期增长量} = \text{报告期水平}-\text{报告期前一期水平}逐期增长量=报告期水平−报告期前一期水平
  • 累计增长量=报告期水平−最初水平\text{累计增长量} =\text{报告期水平}-\text{最初水平}累计增长量=报告期水平−最初水平
  • 平均增长量=逐期增长量合计逐期增长量个数=累计增长量时间序列项数−1=累计增长量最末时间−最初时间\text{平均增长量} = \dfrac{\text{逐期增长量合计}}{\text{逐期增长量个数}} = \dfrac{\text{累计增长量}}{\text{时间序列项数}-1}= \dfrac{\text{累计增长量}} {\text{最末时间}-\text{最初时间}}平均增长量=逐期增长量个数逐期增长量合计​=时间序列项数−1累计增长量​=最末时间−最初时间累计增长量​

时间序列的速度分析

发展速度与增长速度

发展速度

发展速度：报告期水平 / 基期水平，以相对数形式表示的两个不同时期发展水平的比值

  • 定基发展速度：报告期水平与某一固定时期水平（通常是最初水平）的比值
  • 环比发展速度：报告期水平与其前一期水平的比值
  • 定基发展速度 = 相应时期内各环比发展速度的连乘积
  • 两个相邻时期定基发展速度的比率 = 相应时期的环比发展速度

增长速度

增长速度：报告期增长量与基期水平的比值，表明报告期比基期增长（或降低）了百分之几或若干倍

  • 定基增长速度：报告期累计增长量与基期水平的比值
  • 环比增长速度：报告期逐期增长量与基期水平的比值

平均发展速度与平均增长速度

  • 平均发展速度：一定时期内各期环比发展速度的序时平均数，通常采用几何平均法
  • 平均增长速度：一定时期内逐期增长（降低）变化的一般程度，平均增长速度=平均发展速度-1

速度的分析与应用

  • 当时间序列中的指标值出现 0 或负数时，不宜计算速度
  • 速度指标的数值与基数的大小有密切关系
  • 在环比增长速度时间序列中，各期的基数不同，因此，运用这一指标反映现象增长的快慢时，往往要结合“增长 1%的绝对值”分析。

    增长 1%的绝对值=逐期增长量环比增长速度=报告期前一期发展水平×1%\text{增长 1\%的绝对值}=\dfrac{\text{逐期增长量}}{\text{环比增长速度}} = \text{报告期前一期发展水平} \times 1\% 增长 1%的绝对值=环比增长速度逐期增长量​=报告期前一期发展水平×1%

时间序列的分解和预测程序

时间序列的成分

  • 长期趋势（T）：时间序列在较长一段时间内呈现的持续上升或持续下降的变动。可能是线性的，也可能是非线性的
  • 季节变动（S）：时间序列在一年内重复出现的周期性波动
  • 循环波动（C） ：时间序列呈现出的非固定长度的周期性变动
  • 不规则波动（I） ：时间序列中除去长期趋势、季节变动和循环波动之后的随机波动。一般由一些偶然因素引起的，难以预测和控制

时间序列的预测步骤

  1. 确定时间序列所包含的成分
  2. 找出适合该时间序列的预测方法
  3. 对可能的预测方法进行评估，以确定最佳预测方案
  4. 利用最佳预测方案进行预测

平滑预测法

平滑预测法：“消除”时间序列的不规则成分所引起的随机波动，适用于平稳时间序列的预测（没有明显的趋势、循环和季节波动的时间序列）

  • 移动平均法：使用时间序列中离预测期最近 kkk 期数据值的平均数作为下一期的预测值
  • 指数平滑法：利用过去时间序列值的加权平均数作为预测值

    (t+1期的预测值)=λ⋅(t期的实际观察值)+(1−λ)⋅(t期预测值)(t+1 \text{期的预测值}) = \lambda\cdot (t \text{期的实际观察值})+(1 - \lambda)\cdot (t \text{期预测值}) (t+1期的预测值)=λ⋅(t期的实际观察值)+(1−λ)⋅(t期预测值)

    • 观测值离预测时期越久远，其权重也变得越小，呈现出指数下降
