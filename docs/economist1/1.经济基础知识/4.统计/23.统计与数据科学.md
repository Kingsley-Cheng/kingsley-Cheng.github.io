## 统计学

### 统计学的两大分支
==统计学==：关于收集、整理、分析数据和从数据中得出结论的科学

**统计学的两大分支**

- ==描述统计==：研究**数据收集、整理和描述的**统计方法。主要研究内容：
    - 如何取得所需要的数据
    - 如何用图表或数学方法对数据进行整理和展示
    - 如何描述数据的一般特征
- ==推断统计==：研究如何利用样本数据推断总体特征的统计方法
    - ==参数估计==：利用样本信息推断总体特征
    - ==假设检验==：利用样本信息判断对总体假设是否成立

## 变量和数据
==变量==：研究对象的属性或特征，可以有两个或更多个可能的取值

::: table title="变量分类"
|分类1|分类2|含义|
|:---:|:---:|:---:|
|定量变量（数量变量）{colspan=2 rowspan=1}||变量的取值是数量|
|定性变量{colspan=1 rowspan=2}|分类变量|变量的取值是类别|
||顺序变量|变量的取值是类别且有顺序|
:::

==数据==：对变量进行测量、观测的结果

::: table title="数据分类"
|分类|含义|
|:---:|:---:|
|定量数据（数值型数据）|对定量变量的观测结果，取值表现为具体的数值|
|分类数据|分类变量的观测结果，表现为类别，一般用文字来表述，也可用数字描述|
|顺序数据|顺序变量的观测结果，表现为类别，一般用文字描述，也可用数字描述|
:::


## 数据的来源

### 观测数据和实验数据
:::table title="按收集方法划分数据来源"
|种类|含义|
|:---:|:---:|
|观测数据|通过直接调查或测量而收集的数据<br>几乎所有与**社会经济现象**有关的统计数据都是观测数据|
|实验数据|通过在实验中控制实验对象以及其所处的实验环境收集到的数据<br>**自然科学领域**的数据大多都是实验数据|
:::


### 一手数据和二手数据
:::table title="按使用者角度划分数据来源"
|种类|含义|
|:---:|:---:|
|一手数据|来源于**直接的调查和科学实验**的数据，对使用者来说这是数据的直接来源|
|二手数据|来源于**别人的调查或实验的数据**。对使用者来说这是数据的间接来源|
:::

## 统计调查

### 统计调查的概念与分类

==统计调查==：按照预定的目的和任务，运用科学的统计调查方法，有计划有组织地收集数据信息资料的过程

- 调查是一种有计划、有方法、有程序的活动
- 调查的结果表现为收集到的数据

**按调查对象的范围不同**
- ==全面调查==：对构成调查对象的所有单位进行逐一的、无一遗漏的调查
  - 全面统计报表
  - 普查：人口普查、经济普查（第二、第三产业）
- ==非全面调查==：对调查对象中的一部分单位进行调查
  - 非全面统计报表
  - 抽样调查
  - 重点调查
  - 典型调查

**按调查登记的时间是否连续**
- ==连续调查==：观察总体现象在一定时期内的数量变化，说明现象的发展过程，目的是为了解社会现象在一段时期的总量
- ==不连续调查==：间隔相当长的时间（通常一年以上）所做的调查，一般是为了对总体现象在一定时点上的状态进行研究

### 统计调查的方式

在我国常用的统计调查方式有**统计报表、普查、抽样调查、重点调查和典型调查**

==统计报表==：按照国家有关法规的规定，**自上而下地统一布置，自下而上地逐级提供**基本统计数据的一种调查方式
- 统计报表一般**以一定的原始数据为基础，按照统一的表式、统一的指标、统一的报送时间和报送程序**进行填报

::: table
|分类标准|内容|
|:---:|:---:|
|按调查对象范围的不同|全面统计报表、非全面统计报表|
|按报送周期长短不同|日报、月报、季报、年报等|
|按报表内容和实施范围不同|国家的、部门的、地方的统计报表|
:::

==普查==：为某一特定目的而专门组织的一次性全面调查。主要用于了解处于**某一时点状态上**的社会经济现象的基本全貌，为国家制定有关政策提供依据
- 普查通常是**一次性的或者周期性的**
- 普查一般要规定统一的标准调查时间，以避免调查数据的重复或遗漏，保证普查结果的准确性
- 普查数据一般比较准确，规范化程度较高，可以为抽样调查和其他调查提供基本依据
- **适用范围比较窄**，只能调查基本及特定的现象

::: table
|常见普查|实施时间|
|:---:|:---:|
|经济普查|逢年份末尾数字为 3、8 的年份实施|
|人口普查|逢“0”年份实施|
|农业普查|逢“6”年份实施|
:::

==抽样调查==：从调查对象的总体中抽取一部分单位作为样本进行调查，并根据样本调查结果来推断总体数量特征的一种非全面调查
- 经济性（最显著的优点）
- 时效性强
- 适应面广
- 准确性高

==重点调查==：从调查对象的总体中选择少数重点单位进行调查，**所选择的重点单位就调查的标志值来说在总体中占绝大比重**
- 当调查目的**只要求了解基本状况和发展趋势**，不要求掌握全面的数据，采用重点调查就比较适宜
- 重点调查以**较少的投入、较快的速度**取得某些现象主要标志的基本情况或变动趋势

==典型调查==：根据调查的目的与要求，在对被调查对象进行全面分析的基础上，**有意识地选择若干具有典型意义**的或有代表性的单位进行的调查
- 优点：典型调查具有灵活机动、通过少数典型单位即可取得深入翔实的统计资料的优点
- 缺点：受“有意识选出若干有代表性单位”的限制，在很大程度上**受到人们主观认识的影响**。必须同其他调查结合起来使用，才能避免出现片面性

### 统计质量评价标准

**真实性** 

- 要求**统计源头数据**必须**符合统计调查对象的实际情况**，确保统计数据有依据、可溯源 

- 侧重于对**基础数据质量**的评价

**准确性** 

- 要求**统计数据的误差必须控制在允许范围内**，能够为形势判断、政策制定、宏观调控等提供可靠依据

- 侧重于对统计数据**生产科学性**的评价

**完整性** 

- 要求统计数据应当全面完整，**统计范围不重不漏，统计口径完备无缺**

- 侧重于对统计数据**全面系统反映客观实际程度**的评价

**及时性** 

- 要求统计数据生产应当在符合统计科学规律的前提下，**尽可能缩短从调查到公布的时间间隔** 

- 侧重于对统计数据**生产效率**的评价

**适用性** 

- 要求统计数据能够最大限度为用户所用，统计指标紧跟时代发展、切合统计需求

- 侧重于对统计**用户满意度**的评价

**经济性** 

- 要求统计**数据生产应当尽可能降低成本**，统计调查、行政记录、大数据等数据资源得到充分利用 

- 侧重于对统计数据**成本效益**的评价

**可比性** 

- 要求统计数据应当连续、可比，不同时间、空间数据生产**使用规范统一的统计标准和统计原则**

- 侧重于对**统计工作标准化、规范化程度**的评价

**协调性** 

- 要求统计数据**结构严谨、逻辑合理**，各总量数据、结构数据相互之间高度匹配 

- 侧重于对统计数据间**逻辑关系**的评价

**可获得性** 

- 要求**多渠道、多方式公布统计数据**，同时公布相应的统计制度方法，加强数据解读，满足社会需求

- 侧重于**对统计服务质量**的评价

## 数据科学与大数据

### 数据科学

==数据科学==：通过系统性研究获取与数据相关的知识体系的学科
- 提出者：“彼得•诺尔”（丹麦）
- 研究对象：数据
- 研究范围：从“数据”整合成“信息”进而组织成“知识”的整个过程，包含对数据进行采集、储存、处理、分析、表现等一系列活动
- 研究目标：获得洞察力和理解力，通过对数据的分析、来解释、预测、洞见和决策，为现实世界服务
- 涉及领域：统计学、计算机科学、可视化、人工智能、领域知识等

### 大数据
==大数据==：无法在一定时间范围内用常规软件工具进行捕捉、管理和处理的数据集合，是需要新处理模式才能具有更强的决策力、洞察发现力和流程优化能力的海量、高增长率和多样化的信息资产

**大数据的5V特性** 

- **数据量大**：大数据的起始计量单位是 PB、EB或 ZB
- **数据多样化**：类型繁多，包括结构化、半结构化和非结构化的数据
    - ==结构化数据==：存储在数据库里，可以用二维表结构实现表达的数据
    - ==非结构化数据==：数据结构不规则或不完整，没有预定义的数据，包括所有格式的办公文档、文本、图片、报表、图像、音频信息、视频信息等
    - ==半结构化数据==：介于完全结构化数据和完全非结构化数据之间的数据，具有一定的结构性，如员工简历
- **价值密度低**：大数据价值密度的高低与数据总量的大小成反比。
- **数据的产生和处理速度快**：大数据的处理要符合“1 秒定律”。
- **真实性**

### 数据挖掘
==数据挖掘==：从大量的、不完全的、有噪声的、模糊的、随机的实际应用数据中，提取隐藏在其中但又有潜在价值的信息和知识的过程
- 基本特征
    - 数据源必须是真实的、大量的、有噪声的
    - 发现的是用户感兴趣的知识
    - 发现的知识是可接受的、可理解、可运用的
    - 并不要求发现放之四海而皆准的知识，只支持特定的发现问题
- 出发点和核心任务：对数据关系和特征进行探索
- 常见方法
    - ==监督学习==：每个观测单位既有自变量，又有因变量。根据已有的数据集，训练出模型可以根据自变量数据得到因变量预测结果的过程。（分类，回归）
    - ==无监督学习==：每个观测值只有自变量，没有因变量。主要任务是探索数据之间的内在联系和结构。（聚类、降维）
    - ==半监督学习==：监督学习与无监督学习相结合的一种学习方法。数据集中，一部分观测单位既有自变量又有因变量，另一部分观测单位只有自变量，没有因变量，而且没有标签的观测单位数量远大于有标签的观测单位数量
