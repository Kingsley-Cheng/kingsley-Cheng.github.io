## 一、衍生品的基本概念

### 衍生品的定义

==衍生品(derivatives)==：基于标的资产(underlying assets)派生出来的金融产品，本质是具有法律效力的合约(contract)，规范了合约买方和卖方的权利与义务
- ==买方(buyer/holder) / 多头(long position)==：购买衍生品合约的人，在资产价格上升时获利
- ==卖方(seller/writer) / 空头(short position)==：卖出衍生品合约的人，在资产价格下跌时获利


### 衍生品的分类

根据标的资产类型划分

::: table full-width
| 分类 | 标的资产 |
| :------: | :-------: |
| 金融衍生品  | 权益类证券、固定收益证券、货币等  |
| 实物资产衍生品    | 大宗商品     |
| 其他衍生品 | / |
:::

根据衍生品收益(payoff)与标的资产价值的关系划分

::: table full-width
| 分类 | 衍生品 |
| :------: | :-------: |
| 线性衍生品(linear derivatives) | 远期、期货、互换  |
| 非线性衍生品(non-linear derivatives) | 期权 |
:::

### 衍生品的应用

- 公司使用衍生品**管理各类风险**

- 公司发行的债券会嵌入衍生品: **提前赎回债券**、**提前回售债券**等

- **员工薪酬计划**：利用衍生品给予员工在未来以约定的价格购买公司股票的权利

- **资本投资机会**往往含有内嵌期权[+实物期权]
[+实物期权]: 一般为实物期权(real option)，即企业内部用于战略投资决策的期权，标的资产是实物资产

- 购房者的**房屋抵押贷款**中常嵌入衍生品



## 二、衍生品市场参与者

::: table full-width
| 参与者 | 含义 |
| :------: | :-------: |
| 对冲者(hedgers) | 希望使用衍生品工具减少或消除风险敞口  |
| 投机者(speculators) | 希望承担风险并获得高额回报 |
| 套利者(arbitrageurs) | 希望利用资产组合在多个市场间的价格差异，获取无风险收益 |
:::
